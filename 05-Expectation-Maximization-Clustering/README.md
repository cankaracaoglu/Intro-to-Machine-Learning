# 05 — Expectation-Maximization Clustering

Fitting a Gaussian mixture model to two-dimensional data with the EM algorithm, implemented from
scratch and initialized from k-means-style hard assignments.

> Introduction to Machine Learning — Assignment 5

---

## Problem

Cluster 1,000 two-dimensional points drawn from **five bivariate Gaussian densities**, recovering the
mixture parameters without being told which point came from which component.

Because the data is synthetic, the ground-truth parameters are known and the fit can be scored
directly against them:

| Component | True mean | True covariance | N |
|-----------|-----------|-----------------|---|
| 1 | (0.0, +5.5) | diag(4.8, 0.4) | 275 |
| 2 | (−5.5, 0.0) | diag(0.4, 2.8) | 150 |
| 3 | (0.0, 0.0) | diag(2.4, 2.4) | 150 |
| 4 | (+5.5, 0.0) | diag(0.4, 2.8) | 150 |
| 5 | (0.0, −5.5) | diag(4.8, 0.4) | 275 |

The elongated, axis-aligned covariances are what make this a good test case — components 1 and 5 are
wide and flat, 2 and 4 are tall and narrow, so a clustering method that assumes spherical clusters
(plain k-means) will carve them up incorrectly. EM, which fits a full covariance per component, can
follow their true shapes.

## Method

**Initialization.** Starting centroids are read from `hw05_initial_centroids.csv`. Each point is
assigned to its nearest centroid (a single k-means membership step), and those hard assignments seed
the initial per-cluster covariances and mixing priors.

**E-step.** Compute the responsibility `h_ik` — the posterior probability that point `i` was
generated by component `k` — by evaluating each component's Gaussian density at the point, weighting
by the mixing prior, and normalizing across components:

```
h_ik = π_k · N(xᵢ | μ_k, Σ_k) / Σ_j π_j · N(xᵢ | μ_j, Σ_j)
```

**M-step.** Re-estimate the means, covariances, and priors as responsibility-weighted averages over
all points — the soft-assignment analogue of recomputing cluster centers.

The two steps alternate for **100 iterations**, with `K = 5`.

## Results

**Initial priors after the nearest-centroid step:** `[0.063, 0.156, 0.283, 0.223, 0.275]` — a poor
starting point, well off the true mixing proportions of `[0.275, 0.15, 0.15, 0.15, 0.275]`.

**Converged means after 100 EM iterations:**

| Fitted mean | Nearest true mean | Error |
|-------------|-------------------|-------|
| (+0.150, −0.106) | (0.0, 0.0) | ≈ 0.18 |
| (+5.638, −0.017) | (+5.5, 0.0) | ≈ 0.14 |
| (−0.061, −5.601) | (0.0, −5.5) | ≈ 0.12 |
| (−0.085, +5.455) | (0.0, +5.5) | ≈ 0.10 |
| (−5.483, −0.088) | (−5.5, 0.0) | ≈ 0.09 |

EM recovers all five components to within roughly 0.2 units, despite the badly skewed initial priors
— the soft assignments correct the initialization over the first iterations rather than locking it
in the way hard k-means assignments would.

The final figure plots each point colored by its most likely component (`argmax` over
responsibilities), with the fitted Gaussian contours drawn in the matching cluster color and the
true generating densities overlaid as dashed black contours — so the quality of the fit is visible
directly as the gap between the solid and dashed curves.
